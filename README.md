# Sensing-Aided Near-Field Beam Focusing for THz V2X — Code & Results

Public reproduction package for the paper *"Sensing-Aided Near-Field Beam Focusing for
THz V2X: Joint Angle–Range Prediction with Radar and LiDAR Priors."*

This work predicts **near-field (spherical-wavefront) beam-focusing codewords** — joint
**angle × range** — for THz V2X links directly from on-board **radar** and **LiDAR**, so a
small RF verification sweep recovers near-genie beam-focusing gain without an exhaustive
codebook search. The design is **radar-primary**: radar alone drives angle, a polar
(angle×range) codebook supplies range focusing, and a cross-attention fusion branch is
included but does not significantly beat radar on the physical metric. Results are reported
on a pre-registered close-range synthetic V2X scenario (the near-field study), an O1
far-field anchor, and **real DeepSense 6G** radar (V2I Scenario 31, V2V Scenario 36).

> **Every figure and table regenerates from the small banked JSON files in `results/`** via
> one command — no GPU, no large datasets, no retraining required. Each number is traceable
> to a JSON cell (see `paper/audit/` and `paper/canonical_numbers.md`).

## 1. Install

```bash
python -m venv .venv && source .venv/bin/activate     # (Windows: .venv\Scripts\activate)
pip install -r requirements.txt
```

Exact pinned versions are in `requirements.txt` (Python 3.14; key pins: numpy 2.3.5,
matplotlib 3.10.7, h5py 3.15.1, scipy 1.16.3, torch 2.11.0+cu128). **Figure/table
regeneration needs only numpy/matplotlib/scipy/h5py — not torch or a GPU.**

## 2. Regenerate every figure and table (no GPU, no datasets)

```bash
bash scripts/figures/run_all.sh          # Linux/macOS / Git-Bash
# or, on Windows PowerShell:
pwsh scripts/figures/run_all.ps1
```

This reads only `results/*.json` and writes:
`paper/figures/*.{pdf,png}`, `paper/tables/*.{tex,md}`, `paper/canonical_numbers.md`,
`paper/canonical_macros.tex`, and consistency audit trails in `paper/audit/`. It prints
`0 blocking gaps` on success. (The Fig 1 architecture `.tex` is compiled with `pdflatex`
if available; otherwise it is left as an editable TikZ skeleton.)

## 4. Re-derive the banked results (optional; needs GPU + datasets)

The `results/*.json` are committed so figures reproduce instantly. To re-derive them from
scratch you also need the raw datasets (Section 6), the processed `.h5` (regenerated by the
generators), the checkpoints in `checkpoints/`, and a CUDA GPU:

- **Codebook:** `scripts/generate_codebook.py` (uses `src/codebook/polar.py`, `steering.py`).
- **Synthetic data:** `scripts/generate_synthetic_multimodal.py` (O1 anchor),
  `scripts/generate_closerange.py` (pre-registered near-field scenario), `apply_gain_gate.py`.
- **DeepSense processing:** `scripts/process_deepsense_scenario.py` (Sc 31),
  `scripts/process_deepsense_scenario36.py` (Sc 36).
- **Training:** `scripts/train_single.py`, `scripts/train_fusion.py`.
- **Eval / banking:** `scripts/eval_headline.py`, `scripts/degradation_eval.py`,
  `scripts/gate0_verification.py`, `scripts/deepsense_decomp.py`, `scripts/ablate_br_common.py`.
- **Re-bank only (eval, no retrain):** `scripts/figures/bank_results.sh`.

Decisions of record (D-001 … D-017), including the metric and codebook conventions, are in
`docs/decisions.md`. Tests: `pytest -q` (self-contained; the statistics are validated against
SciPy).

## 5. Checkpoints

`checkpoints/` holds the final cited model weights (15 model families × seeds; largest file
≈18 MB, total ≈0.7 GB). **They are NOT required to regenerate figures/tables** (those come
from `results/`); they are provided so the eval steps in Section 4 can be re-run. If the
0.7 GB is undesirable in a Git remote, move `checkpoints/` to a separate Zenodo/Git-LFS
archive and link it here — no individual file exceeds GitHub's 100 MB limit.

## 6. Datasets (NOT redistributed — obtain from the official sources)

The raw sensor datasets are **not** included; download them under their own licenses:

- **DeepMIMO** (synthetic O1 scenario, ray tracing): <https://www.deepmimo.net> — scenario `O1`.
- **DeepSense 6G** (real multi-modal V2X): <https://www.deepsense6g.net> — **Scenario 31**
  (development, V2I/RSU) and **Scenario 36** (V2V). Academic license; do not bypass it.

After obtaining the raw data, the generators/processors in Section 4 produce the processed
`.h5` and then the `results/*.json`.
